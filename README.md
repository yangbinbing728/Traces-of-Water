# Water Traces

A minimal, silent interactive website with four connected scenes: stains, footprints, tears, and rain. No dependencies.

Open index.html to try it locally. Use the bottom navigation, arrow button, or left/right arrow keys to change scenes.

## GitHub Pages

Upload these files, including .github, to the repository root. In Settings → Pages, select GitHub Actions. Push to main to deploy. Alternatively, deploy from the main branch and root folder.
